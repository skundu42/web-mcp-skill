# Privacy notice

Effective date: August 31, 2026

This notice describes the WebMCP Enable instructions-only plugin and its public GitHub support channel, maintained under the [skundu42](https://github.com/skundu42) account. It does not replace the policies of OpenAI, GitHub, your organization, or websites you use.

## The plugin bundle

The bundle contains instructions, metadata, reference documents, and a logo. It includes no executable runtime, analytics SDK, cookies, tracking endpoint, hosted MCP server, or maintainer-operated backend. It does not itself transmit website content, source code, credentials, or conversation history to the maintainer, and it grants the maintainer no access to your Codex tasks or browser sessions.

## When you use the skill

The instructions guide Codex and tools you authorize. Those tools may read source files or pages, consult online documentation, write integration code, and test selected workflows. Task context and results may be processed by OpenAI or other configured providers according to your account, organization settings, and the tools used. Data is not necessarily confined to your device.

An integration generated for a website runs in that website's environment and may use its existing services. A session-local adapter does not mean all associated data processing is local. Review generated code, tool results, permissions, and the target site's policies before use. The instructions require bounded outputs, preservation of authentication and consent, and exclusion of credentials and unnecessary personal information.

See [OpenAI's privacy policy](https://openai.com/policies/privacy-policy/) and the policies applicable to any other providers or websites you choose to use. Their processing is separate from this project's support activities.

## Public support reports

If you open a GitHub issue or contribute to the repository, your GitHub identity and the content you submit are visible to the maintainer and, for public content, other visitors. The maintainer may use that information to answer questions, reproduce bugs, and improve the project. GitHub also processes information under its [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Only submit information you are allowed to share publicly. Never include secrets, production account data, personal records, or private code. Prefer synthetic examples. Public reports and repository history may remain available until removed; this project does not promise automatic deletion or control copies, forks, downloads, or search caches.

## Your choices and contact

You can stop using the skill and uninstall it through the host application or remove a manually installed copy. Uninstalling the skill does not remove generated website changes, undo submitted actions, or delete data held by other providers. Review the removal instructions for each generated integration separately.

You can edit or delete your own GitHub support content where GitHub permits. To ask about a report the maintainer controls, follow the [privacy contact instructions](SUPPORT.md#privacy-questions) without posting additional personal data. Requests concerning OpenAI, GitHub, or a target website must also be directed to that provider where appropriate.
