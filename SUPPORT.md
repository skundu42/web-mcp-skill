# Support

WebMCP Enable is maintained by [skundu42](https://github.com/skundu42). It is an independent, instructions-only plugin; it is not an official OpenAI or browser-vendor product.

## Get help or report a bug

Use [GitHub Issues](https://github.com/skundu42/web-mcp-skill/issues). Search existing issues first, then include:

- The plugin version and the workflow you were trying to implement.
- Whether you used editable source or a URL-only adapter.
- Your browser and agent/client versions, where known.
- Expected behavior, observed behavior, and a minimal reproduction using test data.
- Whether the failure occurs in a mock, the native browser, or the intended agent.

Do not post passwords, cookies, tokens, private URLs, personal records, proprietary source code, or unredacted screenshots/logs. Issues and attachments are public. Use a small synthetic example instead of production data.

For a security concern, do not disclose an exploit against a live site or sensitive details in a public issue. You may post a general request for a private reporting channel without the details. No dedicated confidential support channel is currently advertised by this project.

## Scope and availability

Documentation and support are in English. Support is provided through the issue tracker on a best-effort basis, without a guaranteed response time, service-level agreement, or emergency coverage.

Support covers the plugin's instructions, packaging, and reproducible integration problems. Browser features, third-party services, website permissions, and Codex account access are controlled by their providers. Installing this plugin does not enable browser WebMCP or guarantee compatibility with a particular site or agent.

The publisher supports all countries and territories where OpenAI officially supports ChatGPT/Codex, subject to product availability and platform restrictions, with no additional publisher geographic exclusions. English-language, best-effort support applies throughout that scope. The bundle has no geographic checks of its own; actual directory availability depends on the portal selections and platform. See the [regional policy and listing status](LISTING.md#availability). Regional support does not establish legal suitability for a particular use or native browser compatibility.

## Privacy questions

Read the [privacy notice](PRIVACY.md). For a question about information shared with this project, open an issue containing only a general description and a link to the affected public report. Do not repeat the personal information or credentials you want removed.
